# Poly Haven

Community-funded asset library uit Zuid-Afrika. Bekend als de **CC0 standaard** voor HDRI's, textures en 3D-models — alles royalty-free, geen attributie verplicht, commercial OK.

## Belangrijkste eigenschappen

- **License**: CC0 (public domain) op alle assets
- **Geen account vereist** voor download
- **Resolutions**: 1k tot 16k voor HDRI's en textures
- **Categorieën**: HDRIs (skies, indoor, outdoor, studio), Textures (alle materialen), Models (props, vegetation)
- **Funding**: Patreon + Blender Foundation grant

## Integraties

- **Blender Add-on**: official, één-klik browse + download in viewport
- **blender-mcp**: tools `search_polyhaven_assets`, `download_polyhaven_asset`, `get_polyhaven_categories`, `get_polyhaven_status`, `set_texture` (zie [[ahujasid blender-mcp]])

## Relevant voor cabin-visuals

Eerste stop voor:
- Outdoor HDRI's (lighting + sky)
- Grond-textures (gras, grind, mos, sneeuw, aarde)
- Hout-textures (gevel, deck, vlonder)
- Steen/beton textures (paden, terras)

Voor vegetation + tuinmeubels meestal aanvullend [[Sketchfab]] gebruiken.
