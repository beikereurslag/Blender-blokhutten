# Blokhutwinkel.nl

Nederlandse aanbieder van blokhutten, tuinhuizen, veranda's, garages en houten overkappingen. Showroom in Zutphen — claimt "Europa's grootste" met 100+ permanent uitgestalde modellen. Aanbod: 10.000+ modellen totaal inclusief maatwerk.

## Relevantie voor user

User maakt voor blokhutwinkel.nl visuals: een Twinmotion-bestand was de oorspronkelijke opdracht, maar user vervangt dit door Blender + Claude/MCP-aanpak. Doel: aankleding van geleverde blokhut-modellen in diverse tuinscènes als verkoopvisuals.

## Producten (zie [[Blokhutwinkel.nl - Product Categories]])

- Blokhutten + tuinhuizen
- Veranda's + paviljoens + priëlen
- Houten garages + carports
- Tuinkantoren + chalets + camping pods + pipowagens
- Kapschuren
- Houten overkappingen

## Eigen 3D-service

Blokhutwinkel biedt al een gratis 3D-tekening bij offerte. Dit is technisch (CAD-style). Onze meerwaarde voor hun marketing zit in **sfeer + omgeving + meerdere stijlen** per product — iets wat hun eigen tool niet doet.
