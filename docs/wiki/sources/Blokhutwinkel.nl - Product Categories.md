# Blokhutwinkel.nl — Product Categories

Showroom in Zutphen. Gratis levering NL+BE op orders >€250. 25+ jaar ervaring met maatwerk. Belangrijk voor onze visuals: ze bieden zelf al gratis 3D-tekening — onze Blender-output moet daar boven uit (sfeer, context, photoreal).

## Productcategorieën

| Categorie | Use case | Doelgroep | Bijpassende stijl |
|---|---|---|---|
| **Blokhutten / tuinhuizen** | Recreatie, opslag, kantoor | Brede markt | Modern minimalist, cottage, boerderij |
| **Veranda's** | Outdoor living, terras-uitbreiding | Eigen woning | Cottage, modern, scandi |
| **Paviljoens / priëlen** | Decoratief, schaduw, sfeer | Tuin-liefhebbers | Cottage, japans-zen |
| **Garages (hout)** | Voertuig-opslag | Eigen woning + tweede auto | Boerderij, modern |
| **Tuinkantoren / chalets / pipowagen / camping pods** | WFH, B&B, accommodatie | Recreatie, ondernemers | Bos, scandinavisch |
| **Carports** | Voertuig-overkapping | Eigen woning | Modern, boerderij |
| **Kapschuren** | Gereedschapsopslag | Boerderij, tuin | Boerderij, landelijk |
| **Houten overkappingen** | Patio-overkapping | Eigen tuin | Cottage, modern |
| **Sauna's (impliciet via chalets)** | Welzijn, recreatie | Premium | Scandinavisch + hottub |

## Dakstijlen (productinfo)

Plat, zadel, lessenaar, piramide, wolfeind, boog, schuur, gedraaid, paviljoen — relevant omdat dak silhouette de scene-stijl mede bepaalt (modern → plat; cottage → zadel met overstek; chalet → steile wolfeind).

## Materialen

- Vurenhout / sparrenhout (basis)
- Douglas / lariks (premium, weerbestendig, donkerder)

## Visualisatie-service

> Vraag een offerte aan en ontvang een prijsopgave met 3D weergave.

Concurrent voor onze output: hun gratis 3D is technisch (CAD-achtig). Onze meerwaarde = sfeer + omgeving + meerdere stijlen per product.

## Implicaties voor scenes

1. **Sauna-chalet** → Scandinavisch + hottub + berken + natuursteen
2. **Tuinhuis-kantoor** → Modern minimalist + corten staal + siergrassen
3. **Boerderij-kapschuur** → Landelijk + moestuin + kippen + fruitbomen
4. **Pipowagen / camping pod** → Bos / wildernis + dennen + fire pit
5. **Paviljoen / priëel** → Japans-zen + grind + ahorn + stapstenen of cottage + klimrozen
6. **Veranda met overkapping** → Terras + lounge + warm avondlicht

Voor elke binnengekomen blokhut: kies 3-4 passende stijlen uit de matrix, render variatieset.
