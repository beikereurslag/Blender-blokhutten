# BlendSwap — bruikbare assets voor de blokhutten-scenes

Grondige scan van [blendswap.com](https://blendswap.com/blends/categories) op 2026-07-02.
Aanvullende bron **naast** PolyHaven/Sketchfab — het sterkst voor specifieke props die daar
niet staan (complete tuinsets, sier-ijzeren banken, oude lantaarns, tuinhuisjes, terracotta).

Directe link per item: `https://blendswap.com/blend/<id>` · Preview zonder klikken:
`https://blendswap.com/blend_previews/<id>/0/500`

---

## ⚠️ Lees dit eerst — 3 regels

1. **Gratis account** vereist om te downloaden (rechtsboven "Register"). Browsen kan zonder.
2. **Licentie = commercieel veilig houden.** Blokhutwinkel is commercieel, dus:
   - `CC0` → vrij, geen verplichting.
   - `CC-BY` / `CC-BY-SA` → oké, **mits naamsvermelding** (houd een credits-lijstje bij).
   - `CC-BY-NC` / `CC-BY-NC-SA` → **NIET gebruiken** (non-commercieel). Deze heb ik weggelaten.
3. **Blender-versie let op.** Veel toppers zijn B2.5–2.7 **"Blender Internal"**: de *geometrie*
   importeert prima, maar de *materialen* zijn dood in Blender 2.8+ (worden zwart/roze).
   → importeer de mesh en hermaterialiseer met je eigen PBR-workflow (past toch bij de
   realism-overhaul). Items met engine **Cycles/Eevee** behouden hun materialen beter.
